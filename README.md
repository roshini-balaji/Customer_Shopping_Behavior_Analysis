# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using transactional data to uncover insights into customer preferences, purchasing patterns, revenue trends, and subscription behavior. The project combines Python, SQL, Power BI, and business reporting to transform raw data into actionable business insights.

## Dataset

The dataset contains customer shopping records, including:

* Customer demographics (Age, Gender, Location)
* Subscription status
* Product categories and purchased items
* Purchase amounts
* Review ratings
* Shipping methods
* Discount and promotional information
* Purchase frequency and history

**Dataset Size:** 3,900 records with 18 features.

* **Python** – Data cleaning, preprocessing, and Exploratory Data Analysis (EDA)

## Project Workflow

### 1. Data Loading & Exploration

* Loaded the dataset using Python.
* Examined data structure, data types, and summary statistics.
* Identified missing values and data quality issues.

### 2. Data Cleaning & Preparation

* Handled missing values.
* Standardized column names.
* Removed redundant fields.
* Created new features such as age groups for better analysis.

### 3. Exploratory Data Analysis (EDA)

* Analyzed customer demographics.
* Explored purchase behavior and spending trends.
* Studied subscription patterns.
* Examined product category performance.
* Visualized key insights using charts and graphs.

### 4. SQL Analysis (PostgreSQL)

Performed business-focused SQL queries, including:

* Revenue analysis by gender.
* Subscriber vs non-subscriber comparison.
* High-spending customer identification.
* Top-rated products analysis.
* Customer segmentation.
* Revenue contribution by age group.
* Product category performance evaluation.

### 5. Power BI Dashboard

Built an interactive dashboard to monitor:

* Customer count
* Average purchase amount
* Average review rating
* Subscription distribution
* Revenue by category
* Sales by category
* Revenue by age group
* Sales by age group

Dashboard filters:

* Subscription Status
* Gender
* Category
* Shipping Type

### 6. Reporting & Presentation

* Created a detailed project report summarizing methodology and findings.
* Developed a professional presentation using Gamma to communicate business insights and recommendations.

The Power BI dashboard provides an interactive view of customer behavior and business performance through KPIs, charts, and filters, enabling quick decision-making and trend analysis.
